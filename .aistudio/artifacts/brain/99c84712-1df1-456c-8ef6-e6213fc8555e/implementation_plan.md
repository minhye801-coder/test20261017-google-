# 영양자료 자동 생성기 (초등학교 급식 영양·식생활 교육자료 제작 웹앱)

초등학교 영양교사가 매일의 급식 메뉴를 활용하여 학생들의 눈높이에 맞춘 '오늘의 음식 이야기', '영양 정보', '재미있는 퀴즈' 교육자료를 손쉽고 빠르게 제작하고, 급식실 TV 전체화면 송출 및 인쇄·이미지로 내보낼 수 있는 순수 정적 웹 애플리케이션입니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 사전 질의응답 및 상충 조건 검토를 통해 확정된 핵심 설계 기준입니다.

- **데이터 보관 및 초기화 방침 (확정)**: 브라우저 JavaScript 메모리(객체 상태)에만 안전하게 보관하며, 외부 전송이나 무단 저장을 하지 않습니다. 사용자가 실수로 데이터 손실을 겪지 않도록 상단에 "새로고침 시 입력 내용이 초기화됩니다"라는 명확한 안내 문구와 JSON 내보내기/불러오기 백업 기능을 기본 제공합니다.
- **이미지 저장 및 인쇄 지원 (확정)**: 외부 npm/CDN 라이브러리(`html2canvas` 등) 없이 순수 웹 브라우저 API(SVG `<foreignObject>` 기반 Canvas 렌더링 to PNG 다운로드)와 브라우저 인쇄 전용 CSS(`@media print` 최적화 레이아웃)를 **모두 제공**합니다.
- **초등 다빈도 10대 메뉴 내장 데이터 (확정)**: 비빔밥, 쇠고기미역국, 제육볶음, 돈가스, 잔치국수, 카레라이스, 닭볶음탕, 떡국, 마파두부, 삼계탕 등 초등학교 선호 급식 메뉴 10종에 대한 검증된 음식 이야기, 주요 영양소 정보, 학년별 퀴즈(저학년용 O/X 및 쉬운 3지선다, 고학년용 식생활 상식 퀴즈)를 기본 템플릿으로 내장하여 클릭 한 번으로 불러올 수 있도록 구현합니다.
- **기술 스택 및 배포 환경 (확정)**: 빌드 도구나 프레임워크 없는 순수 `index.html`, `style.css`, `app.js` 3개 파일 체제로 구성하며, GitHub Pages 정적 호스팅 환경에 즉시 배포 가능하도록 상대 경로(`href="./style.css"`, `src="./app.js"`)로 연결합니다. 추가 가이드 파일로 `setup.md`(구글 스프레드시트 및 Apps Script 연동 설명서)를 함께 작성합니다.

## 1. Overview & Core Concept

- **목적**: 영양교사의 매일 반복되는 식생활 안내자료 제작 업무 부담을 획기적으로 줄이고, 급식 메뉴와 연계된 흥미로운 교육 콘텐츠를 통해 학생들의 편식 예방과 급식 만족도를 향상시킵니다.
- **주 사용자**: 초등학교 영양교사 (간편한 입력, 검증된 내용 수정, TV 송출, 게시판 인쇄물 제작)
- **주 수혜자**: 초등학교 1~6학년 학생 (급식실 대형 모니터 및 배식대 앞 출력물로 오늘의 급식 상식과 퀴즈를 확인)
- **핵심 가치**:
  1. *검증된 데이터 기반*: 임의의 가짜 수치를 생성하지 않고, 영양성분이 확인되지 않은 경우 '정보 확인 필요' 상태를 정직하게 표시.
  2. *초등 맞춤형 디자인*: 화이트·민트 중심의 산뜻하고 정갈한 비주얼과 학년군별 가독성 높은 글씨 크기 자동 조절.
  3. *완전한 독립 정적 웹*: 별도 서버나 외부 유료 API 결제 없이 브라우저 단독으로 100% 동작.

### 시각적 디자인 테마 (Visual Identity & Theme)
- **컬러 팔레트**:
  - 60% 캔버스: 순백색(`bg-white` / `#FFFFFF`) 및 연한 민트 틴트 배경(`bg-[#F4FAF8]`)
  - 30% 구조면: 산뜻한 민트 보더(`border-[#A7F3D0]`, `border-[#D1FAE5]`) 및 카드 배경(`bg-white`)
  - 10% 포인트 액센트: 포레스트 민트(`bg-[#0D9488]` / `text-[#0D9488]`, 호버 시 `#0F766E`), 퀴즈 정답 강조 앰버/에메랄드
- **타이포그래피 및 학년별 가독성 조절**:
  - 시스템 기본 고딕 폰트(`Pretendard`, `-apple-system`, `BlinkMacSystemFont`, `Noto Sans KR`)를 적용하여 어떤 환경에서도 선명하게 표시
  - **저학년(1~2학년)**: 폰트 크기 `text-xl` ~ `text-2xl`, 줄간격 `1.8`, 쉬운 낱말과 짧은 문장 위주 레이아웃
  - **중학년(3~4학년)**: 폰트 크기 `text-lg` ~ `text-xl`, 균형 잡힌 설명문
  - **고학년(5~6학년)**: 폰트 크기 `text-base` ~ `text-lg`, 상세 영양소 원리와 식습관 상식 수록
- **TV 전체화면 모드**:
  - 급식실 55~75인치 대형 TV에 송출할 수 있도록 16:9 비율 최적화
  - 원거리에서도 잘 보이는 특대형 글자(`text-3xl` ~ `text-5xl`), 높은 명도 대비, 여백의 미를 살린 레이아웃
  - ESC 키 또는 화면 클릭/닫기 버튼으로 간편하게 복귀

## 3. 핵심 규칙 (Core Rules)

1. **엄격한 데이터 정직성 (Zero Hallucination Rule)**:
   - 영양 정보는 교사가 직접 입력하거나 검증된 내장 템플릿의 데이터만 사용합니다.
   - 영양 정보 필드가 비어 있거나 검증되지 않은 경우, 임의의 수치나 가짜 칼로리를 자동 계산하지 않고 **`[영양 정보 확인 필요]`** 안내 태그를 명시합니다.
2. **필수 입력값 검증 (Validation Rule)**:
   - 날짜와 급식 메뉴는 필수 항목입니다. 미입력 시 미리보기에 "날짜와 메뉴를 먼저 입력해주세요" 플레이스홀더를 표시하고 내보내기/전체화면 동작을 방지합니다.
   - 퀴즈 작성 시 정답 번호가 선택되어 있지 않으면 "퀴즈 정답을 선택해주세요" 경고 및 저장 방지 처리를 수행합니다.
3. **학생 및 개인정보 보호 (Zero PII Rule)**:
   - 학생 이름, 학번, 식별번호 등 어떠한 개인정보도 입력받거나 수집하지 않습니다.
4. **순수 정적 웹 무의존성 (Zero External Dependency Rule)**:
   - 외부 CDN 스크립트나 외부 폰트, npm 패키지 없이 순수 브라우저 내장 기능만으로 완성합니다.
5. **안전한 DOM 조작**:
   - 사용자 입력값 렌더링 시 XSS 공격을 방지하기 위해 `innerHTML`을 사용하지 않고 `textContent` 및 안전하게 격리된 DOM 생성 방식을 적용합니다.

## 5. 이번 버전에서 제외할 기능 (Out of Scope for this Version)

순수 정적 웹의 간결성과 안정성을 극대화하기 위해 다음 기능은 의도적으로 제외합니다:
1. **백엔드 서버 및 원격 데이터베이스**: 서버리스 API, Firebase, Cloud SQL 등 원격 DB 연결을 배제하고 메모리 및 JSON 파일 백업 방식으로 개인정보 및 외부 유출 위험을 0%로 유지합니다.
2. **AI LLM API 실시간 자동 생성**: 교사의 검증 없는 임의의 영양소 수치 생성 오류를 원천 차단하기 위해 실시간 LLM API 호출을 배제하고, 철저히 검증된 초등 10대 영양 템플릿 데이터베이스를 내장합니다.
3. **외부 무거운 라이브러리 탑재**: 빌드가 필요한 React, Vue, tailwind cli 빌드 번들, 대용량 html2canvas 라이브러리는 제외하고 순수 바닐라 JS/CSS 기법을 사용합니다.
4. **회원가입, 로그인 및 결제 시스템**: 인증 없이 교사가 언제 어디서든 즉시 접속해 무료로 사용할 수 있도록 유지합니다.

## 6. 직접 실행할 검사 순서 (Verification & Test Procedure)

### [A] 정상 동작 검사 (Happy Paths)
1. **기본 입력 및 즉시 반영 검사**:
   - 일자, 학년(중학년 3~4학년), 메뉴 4개("귀리밥, 꽃게된장국, 닭봉조림, 깍두기") 입력.
   - 소개 메뉴로 "꽃게된장국" 선택 시 미리보기 상단 타이틀에 "꽃게된장국"이 즉시 반영되는지 확인.
2. **초등 10대 추천 메뉴 자동 채우기 검사**:
   - "추천 메뉴에서 불러오기" 버튼 클릭 후 "비빔밥" 선택.
   - 음식 이야기, 영양 정보, 퀴즈 내용이 즉시 폼과 미리보기에 정확히 채워지는지 확인.
3. **학년군 변경에 따른 반응형 타이포그래피 검사**:
   - 학년을 "저학년(1~2학년)"으로 변경 시 미리보기 글자 크기가 확대되고 줄간격이 넓어지는지 확인.
   - 학년을 "고학년(5~6학년)"으로 변경 시 단정한 크기로 변경되는지 확인.
4. **퀴즈 인터랙션 검사**:
   - 미리보기 영역에서 퀴즈 보기를 클릭했을 때, 정답/오답 피드백과 함께 해설 박스가 매끄럽게 펼쳐지는지 확인.
5. **TV 전체화면 모드 검사**:
   - [TV 전체화면] 버튼 클릭 시 브라우저 뷰포트 전체에 대형 16:9 슬라이드 화면이 뜨는지 확인.
   - 우측 상단 닫기 버튼 및 `ESC` 키 입력 시 원래 화면으로 정상 복귀하는지 확인.
6. **이미지 다운로드 및 인쇄 검사**:
   - [PNG 이미지 저장] 클릭 시 다운로드 폴더에 `영양교육자료_비빔밥_20261017.png` 파일이 정상 다운로드되는지 확인.
   - [인쇄하기] 클릭 시 브라우저 인쇄 창이 뜨며, A4 용지 1장에 군더더기 없이 우측 미리보기 영역만 깔끔하게 레이아웃되는지 확인.
7. **JSON 내보내기 및 복원 검사**:
   - [JSON 백업] 클릭하여 `.json` 다운로드 후, 폼 내용을 임의로 수정한 뒤 [JSON 불러오기]로 해당 파일을 업로드했을 때 기존 작성 내용이 100% 동일하게 복원되는지 확인.

### [B] 예외 및 유효성 검사 (Edge Cases)
1. **날짜 또는 메뉴 미입력 시**:
   - 날짜를 비우거나 메뉴를 입력하지 않은 상태에서 저장/전체화면 버튼 클릭 시 경고 토스트가 표시되며 제작 프로세스가 안전하게 차단되는지 확인.
2. **영양 정보 미입력 시 임의 수치 생성 방지**:
   - 영양 정보 항목을 모두 비웠을 때, 미리보기에 가짜 칼로리나 수치가 나타나지 않고 `[영양 정보 확인 필요]`라는 중립적 안내가 뜨는지 확인.
3. **퀴즈 정답 미설정 시**:
   - 문제를 입력하고 보기를 입력했으나 정답 라디오를 체크하지 않은 경우 안내 메시지가 나타나는지 확인.
4. **비정상 JSON 파일 불러오기 시**:
   - 텍스트 파일이나 깨진 JSON을 불러왔을 때 앱이 숨거나 멈추지 않고 "올바른 영양자료 파일이 아닙니다" 오류 알림을 띄우며 기존 작성 내용을 안전하게 유지하는지 확인.
